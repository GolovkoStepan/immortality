# Не-цели v0.1

Список зафиксирован, чтобы объём не расползался. Каждый пункт — кандидат на v0.2+,
но не раньше, чем v0.1 пройдёт критерии готовности из [roadmap.md](roadmap.md).

| Не входит | Почему | Когда вернёмся |
| --- | --- | --- |
| TUI на `ratatui` | Демон и CLI `attach` — ядро; TUI рисуется поверх готового API | v0.2 |
| Веб-клиент, WebSocket, мобильный просмотр | Тот же API, другой транспорт | после v0.2 |
| `web_fetch` и любой веб-поиск | Сразу тянет сеть, allowlist по доменам и парсинг HTML | v0.2 |
| PTY-сессии и эмуляция экрана (`vt100`) | В v0.1 хватает `shell` (процесс на команду, D-058) и фоновых процессов через `start_process` | по факту потребности |
| Управление tmux/чужими сессиями | Отдельный инструмент поверх PTY | v0.3+ |
| Linux/Windows демон | launchd, пути, сигналы, PTY — всё разное | ~~по запросу~~ **Linux — `0.2`, см. D-110**; Windows — по запросу |
| Автоматический merge в `main` | Неделя автономной работы превращает main в кашу | после метрик качества |
| Автоматический `git push` | Всегда человеческое действие | не планируется |
| RAG / векторная память | Файлового состояния и grep по журналу достаточно | после метрик |
| Мультипроектность в одном демоне | Демон обслуживает много задач, но каталоги не смешивает; кросс-проектные прогоны не нужны | не планируется |
| Второй inference-слот по умолчанию | Бэкенд последовательный; ключ `backend.max_inference_concurrency` принимается и валидируется, но в v0.1 не читается — второго слота нет даже при значении 2 | при появлении второго сервера |
| Anthropic-совместимый `/v1/messages` | Свой протокол инструментов строится вокруг OpenAI-формата | не планируется |
| Автономный `git push`, публикация пакетов, релизы | Необратимые внешние эффекты | никогда автоматически |
| Работа без интернета вообще (offline-first модель) | Бэкенд в LAN, это не про эту систему | не планируется |
| Поддержка 7B-класса как целевого | Целевой класс — 27B/MoE-30B; мелкие модели допустимы, но не оптимизируем | нет |
| Интернационализация интерфейса | Интерфейс английский, документация русская | нет |
